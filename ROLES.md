# Posh Certify roles

## Housekeeper
- Login with own PIN
- See only assigned rooms
- Take photo and video
- Submit to duty manager
- Cannot certify, add staff, set WhatsApp, or start the shared queue

## Duty manager
- See all rooms
- Certify and notify front desk WhatsApp
- Add/remove staff, set PINs, locations, rooms
- Set duty-manager and front-desk WhatsApp numbers
- Start shared hotel queue

## Front desk
- Login as Front Desk (demo PIN 1100)
- See submitted and certified rooms
- Sell only when status is CERTIFIED
- Cannot submit, certify, or manage staff
